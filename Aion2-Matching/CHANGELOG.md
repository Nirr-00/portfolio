- **보안 취약점 패치 (Rate Limiting 및 입력 검증)**
  - `pre-deploy-security-audit` 에이전트 감사 결과 도출된 Server Actions 계층의 어뷰징/악성 페이로드 공격 취약점 완벽 보완.
  - 외부 API 라우트뿐만 아니라 `recruitActions.ts`, `profileActions.ts`, `applicationActions.ts` 내 모든 갱신 로직에 `rateLimiter`를 도입하여 로그인된 유저 ID 기준 1분당 5~10회 요청 제한(Rate Limiting) 적용.
  - 클라이언트 폼 우회를 통한 초대용량 텍스트 폭탄 삽입을 방지하기 위해 `createRecruit`, `updateRecruit` 시 서버사이드에서 제목 100자, 본문 2000자 이내로 데이터 형식 및 길이를 재검증하도록 강화.
- **Supabase 인증 쿠키 동기화 문제 해결**
  - 클라이언트 사이드 로그인 시 세션이 `localStorage`에만 저장되어, Server Action(대표 캐릭터 정보 업데이트 등) 호출 시 쿠키가 전달되지 않아 "로그인이 필요합니다" 에러가 발생하는 버그 수정.
  - `src/lib/supabase-client.ts`의 클라이언트 생성 방식을 `@supabase/supabase-js`의 `createClient`에서 `@supabase/ssr`의 `createBrowserClient`로 마이그레이션하여, 로그인 시 브라우저 쿠키에 인증 정보가 정상적으로 저장되도록 조치함.
- **TypeScript `any` 타입 엄격화 및 빌드 에러 해결**
  - Vercel 환경에서 `npm run build` 시 발생하던 `Type error: Parameter 'app' implicitly has an 'any' type` 및 `Property 'user_id' does not exist on type 'never'` 등의 연쇄적인 타입 추론 문제들을 모두 해결.
  - 에이전트 룰에 의거하여 `any` 타입을 철저히 배제:
    - `src/app/HomeClient.tsx`의 맵핑 콜백 매개변수 타입을 구체적인 인터페이스(`{ post_id: number }`)로 명시함.
  - `src/lib/supabase-client.ts`에서 명시적인 타입 단언(`ReturnType<...>` 등)을 제거하고 `createBrowserClient`에서 반환되는 고유의 제네릭 타입을 자연스럽게 추론하도록 수정하여 프로젝트 전체의 `getSession()` 및 `from()` 호출부 에러를 완벽하게 차단함.
- **RSC (React Server Component) 아키텍처 리팩토링**
  - 기존 클라이언트 컴포넌트 내부에서 세션(`getSession`)을 가져오던 구조를 서버 컴포넌트(`page.tsx`)에서 세션을 검증하고 클라이언트 컴포넌트 폼(`RecruitForm`, `BusForm`, `ProfileForm`)으로 최소한의 필요 정보만 넘겨주는 형태로 완전히 분리함.
  - 이로 인해 페이지 렌더링 시 세션 체크 딜레이(깜빡임)가 사라지고, 초기 렌더링 성능 및 보안 측면에서 대폭 개선됨.
- **타입 가드(Type Guards) 기반 런타임 안정성 강화**
  - DB에서 내려온 문자열이 클라이언트가 기대하는 타입과 정확히 일치하지 않을 때 발생할 수 있는 잠재적 런타임 오류 방지를 위해 `as` 타입 단언을 제거함.
  - `isValidRecruitType`, `isValidRace`, `isValidRole` 등 명시적인 타입 가드 함수를 도입하고 유니온 타입을 확장하여 데이터 매핑 시 원천 차단.

## [v1.2.0] Server Actions 리팩토링, 공통 컴포넌트 통합 및 무한 스크롤 구현
- **보안 및 안정성 강화 (Security)**
  - 기존 브라우저(Client)에서 직접 호출되던 DB 삭제/수정 쿼리를 모두 Next.js **Server Actions** (`recruitActions.ts`) 기반으로 이관
  - `SUPABASE_SERVICE_ROLE_KEY`를 활용해 서버단에서만 RLS를 우회하도록 설계하여, 사용자의 데이터베이스 임의 변조 시도를 원천 차단
- **압도적인 코드 중복 제거 (Refactoring)**
  - 파티 모집 및 버스 모집 상세 페이지에 복붙되어 있던 약 400줄 이상의 거대 중복 코드를 단일 `<PostDetail>` 컴포넌트로 통합
  - 리스트 페이지(`recruits/page`, `buses/page`) 역시 완전히 동일한 구조를 띄고 있어 `<BoardList>` 공통 컴포넌트로 분리, 유지보수 피로도를 획기적으로 낮춤
  - 하드코딩되어 있던 직업군, 던전 목록 등은 `src/constants/options.ts` 로, 날짜 계산 로직은 `src/utils/dateUtils.ts` 로 완전 분리
- **성능 최적화 (Performance)**
  - 전체 데이터를 브라우저로 한 번에 가져와서 자바스크립트로 필터링하던 낡고 무거운 방식을 전면 폐기
  - 데이터베이스(Supabase) 측에 직접 조건(`.eq`, `.or`)을 전달하고 20개씩 끊어서 가져오는 **서버사이드 페이지네이션(Load More)** 무한 스크롤 구현 완료
- **디자인 및 디테일 강화 (UX & SEO)**
  - 데이터 로딩 시 텍스트만 덜렁 나오던 화면을 제거하고, 세련된 반짝임 효과의 전역 뼈대 애니메이션 UI(`SkeletonCard`, `loading.tsx`) 도입
  - Next.js `Metadata` 설정을 통해 완벽한 검색 엔진 최적화(SEO) 반영 및 카카오톡 링크 공유 시 예쁜 썸네일(OpenGraph)이 나오도록 설정
- **아키텍처 및 디렉토리 최적화**
  - 전체 파일 내 `../../../lib` 등의 구시대적 상대 경로를 Next.js의 가독성 높은 절대 경로 Alias(`@/`)로 일괄 교체 (`@/components`, `@/lib`, `@/utils` 등)
- **타입 안정성 강화**
  - `<Header>`, `recruits/[id]/page`, `buses/[id]/page` 내에 방치되어 있던 `any` 타입을 `Session`, `User`, `Recruit` 등 엄격한 객체 타입으로 전환하여 방어
- **UI/UX 및 웹 접근성(A11y) 강화**
  - 전역 토스트(Toast) 알림 시스템 도입 (`ToastContext`): 기존의 투박한 브라우저 기본 `alert` 팝업 창을 하단에서 부드럽게 등장하는 토스트 알림으로 교체하여 조작 편의성 극대화
  - 시각장애인 및 키보드 유저를 위해 주요 `<button>`, `<input>`, `<select>` 태그에 `aria-label` 속성 전면 적용

## [v1.1.0] 캐릭터 본인 인증 시스템 및 마이페이지 프로필 기능

### ✨ 새로운 기능 (New Features)
- **모집글 수정 기능 (Edit Post)**
  - 본인이 작성한 파티/버스 모집글을 상세 페이지에서 직접 수정할 수 있는 전용 페이지(`edit`) 추가
  - 데이터 변조 방지를 위해 작성자 본인만 접근 및 수정이 가능하도록 서버 기반(`Server Action`) 검증 로직 탑재
  - 수정 폼 로드 시 기존 모집글 데이터 자동 바인딩(Pre-filling) 지원, 닉네임 및 인증 정보 등 주요 정보는 비활성화 처리하여 데이터 무결성 보호
- **캐릭터 본인 확인 인증 (칭호 기반)**
  - 사용자가 게임 내에서 칭호를 '[지켈의 근원을 마주하다], [카이시넬의 근원을 마주하다]'로 변경한 뒤 마이페이지에서 인증 버튼을 누르면, 게임 공개 웹 데이터를 통해 검증하여 본인 캐릭터임을 확인하는 기능 구축
  - 인증된 유저가 작성한 파티/버스 모집글에는 닉네임 우측에 파란색 **[인증 완료 ✅]** 뱃지를 표시하여 신뢰도 대폭 상승
- **마이페이지 정보 수정 및 폼 자동 완성**
  - 가입한 계정의 닉네임 및 비밀번호 변경 기능 추가
  - 마이페이지에 저장해 둔 본인의 대표 캐릭터 정보(종족, 서버, 닉네임)가 파티 및 버스 모집글 작성 시 입력 폼에 자동으로 채워져 글쓰기 편의성 개선

### ⚡ 성능 및 구조 개선 (Refactoring & Optimization)

  - 모집글 상세 페이지 하단의 액션 버튼 영역을 사용자 역할(작성자/비작성자)에 따라 가장 직관적이고 깔끔한 형태로 분리
  - **작성자 전용 뷰**: `[모집 마감]`, `[수정하기]`, `[삭제하기]` 3개의 관리 버튼만 노출하여 본인 글 관리 효율성 극대화
  - **일반 유저(비작성자) 전용 뷰**: 의미 없는 관리 버튼들을 모두 숨기고, 오직 `[신청하기]`(또는 모집완료) 와 `[신청 취소하기]` 2개의 필수 액션 버튼만 나란히 꽉 차게 표시하여 UI 시인성 개선
- **모집글 작성 및 카드 표시 개선**
  - 모집글 작성 시, 특정 역할군(탱커/딜러/힐러)의 직업을 모두 선택하면 카드 화면에서 지저분하게 나열되지 않고 해당 역할군 이름으로 깔끔하게 요약 표시되도록 로직 개선
  - 카드 썸네일 디자인을 정돈하여 닉네임, 인증 마크, 종족, 서버가 한눈에 잘 들어오도록 레이아웃 최적화
  - 버스 모집글 작성 시 직업 선택란을 체크박스 박스 형태로 개선
- **모집글 신청 경험(UX) 업그레이드**
  - 신청 모달이 뜰 때 배경이 완전히 까매지던 현상을 없애고, 뒤쪽의 모집글 본문을 보면서 신청할 수 있도록 투명도 조정
  - 신청 성공 시 딱딱한 브라우저 기본 알림창(`alert`)을 제거하고, 화면 하단에서 부드럽게 나타났다 사라지는 **토스트(Toast) 알림** 기능 도입
  - 본인이 이미 신청한 모집글의 경우, 하단 버튼이 회색의 **[이미 신청한 글입니다]** 상태로 변경되어 중복 신청 방지
  - 모집글 리스트(카드 뷰) 화면에서도 카드 우측 상단에 파란색 **[신청완료]** 띠(리본) 배지를 노출하여, 굳이 상세 페이지에 들어가지 않아도 신청 여부를 한눈에 파악할 수 있도록 직관성 강화
- **캐릭터 전적 검색 기능 디테일 강화**
  - 메인 페이지 및 사이드바 검색기에서 서버가 '모든 서버'로 되어 있을 때, 닉네임 입력 칸을 잠그고 '서버를 먼저 선택해주세요'라는 안내 문구를 노출하여 사용자 혼선 방지

## [v1.0.0] 프로젝트 초기 릴리즈 및 캐릭터 전적 검색 시스템 구축

### ✨ 새로운 기능 (New Features)
- **캐릭터 전적 검색 시스템 구축**
  - 공개 캐릭터 검색 데이터를 연동하여 아이온2 캐릭터 데이터를 화면에 출력
  - 닉네임 검색 시 캐릭터 아바타, 레벨, 직업, 실제 종합 전투력 및 아이템 레벨을 파싱하여 출력
  - 브라우저 CORS 제약을 우회하기 위해 Next.js 백엔드 프록시 라우트 신규 구축
- **전역 플로팅(Floating) 검색 사이드바 도입**
  - 사용자가 메인 화면뿐만 아니라 파티/버스 게시판 등 어느 페이지에 있더라도 스크롤 상태와 무관하게 즉시 검색이 가능하도록 좌측 슬라이드형 사이드바 추가
  - 화면 좌측 탭을 클릭하면 슬라이드-인(Slide-in) 애니메이션과 함께 등장하며, 바깥 영역 클릭 시 자동으로 닫히는 UX 구현
- **모집글 다중 직업 선택 지원**
  - 파티원 모집(구인) 작성 시 여러 개의 직업을 동시에 체크박스로 다중 선택할 수 있도록 로직 및 UI 추가
  - 모집 직업 선택 화면을 역할군별 직업 체크박스 형태로 전체 개선 (구직 시 단일 선택, 구인 시 다중 선택)
  - 파티 및 버스 모집글 작성 시 모집 유형(구인/구직, 기사/승객)이 기본적으로 미선택 상태가 되도록 변경하여 명시적인 선택 유도
- **모집글 상세 설명 추가**
  - 파티 모집글 작성 페이지에 상세 설명을 입력할 수 있는 텍스트 영역 추가
  - 파티/버스 모집글 상세 보기 페이지에서 입력된 상세 설명이 표시되도록 구현

### 💄 UI/UX 개선 (UI/UX Improvements)
- **검색 결과창 플로팅 드롭다운 UI 적용**
  - 홈 화면 메인 배너에서 검색 시 배너 영역이 늘어나는 레이아웃 시프트(Layout Shift) 문제를 해결
  - 검색 결과가 검색창 하단에 절대 좌표(Absolute)로 공중에 뜬 듯이 표시되는 드롭다운 형태의 UI 적용
  - 결과창의 배경을 어두운 반투명 블러(Glassmorphism)로 처리하여 RPG 게임 특유의 묵직하고 고급스러운 디자인 분위기 연출
- **직업 분류 기준 변경**
  - 모든 모집 화면에서 '검성' 직업을 '탱커' 역할군에서 제외하고 '딜러' 역할군으로만 분류하도록 수정
- **작성자 명칭 변경**
  - 모든 카드(파티 카드, 버스 카드) 및 상세 페이지에서 '작성자' 텍스트를 '닉네임'으로 직관적으로 변경
- **상세 페이지 레이아웃 개선**
  - 등록일시 정보가 가장 먼저 보이도록 페이지 최상단으로 위치 이동
  - 닉네임 폰트 스타일 및 색상(text-gray-700)을 다른 상세 정보(서버, 직업, 시간 등)와 일관성 있게 통일
- **메인 페이지 레이아웃 정렬**
  - 필터 확장 시에도 우측 '새 글쓰기' 및 버튼 요소들이 일렬로 깔끔하게 정렬되도록 레이아웃 수정
- **리스트 최신순 정렬**
  - 모집글 전체 보기 및 버스글 전체 보기 리스트가 기본적으로 최신 등록순(최신 글이 상단)으로 노출되도록 기본 정렬 기준 변경
- **리스트 필터 조건 변경**
  - 파티글 및 버스글 전체 보기 페이지에서 기존 '서버' 기준 필터를 '종족' 기준 필터로 변경
  - 필터 옵션 노출 순서를 '천족' → '마족' 순으로 정렬
  - 역할 필터의 명칭을 '역할군'(모든 역할군, 탱커, 딜러, 힐러)으로 수정하여 직관성 개선
- **메인 페이지 필터 박스 정렬 및 UI 개선**
  - 메인 페이지의 필터 팝업 내 역할군 옵션 순서를 기존 자동 정렬 방식에서 '탱커' → '딜러' → '힐러' 고정 순서로 개선
  - 필터 선택 시 필터 버튼 옆에 표시되어 레이아웃을 변형시키던 숫자 뱃지(활성화된 필터 개수) 기능 제거
